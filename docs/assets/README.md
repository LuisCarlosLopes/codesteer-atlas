# Assets do site

Logo CodeSteer e logos dos editores obtidos de https://codesteer.vercel.app/
(`/brand/codesteer-logo.svg` e `/logos/`), conforme a referência visual solicitada.
As marcas pertencem aos respectivos titulares.

Fontes Sora, DM Sans e JetBrains Mono, hospedadas localmente a partir dos
arquivos WOFF2 usados pela referência. Licenças SIL Open Font License nos
arquivos `*-OFL.txt` desta pasta, obtidas no repositório google/fonts.
